# lva-installer

Lva-installer is a typescript-based installer for [lva-os](https://github.com/aryanhasgithub/lva-installer), which uses the etcher-sdk to install lva-os onto a storage device(USB Drive, Micro SD Card, SSD etc). Lva-installer allows you to write a WIFI SSID and a password to the storage device, if you do not want to use ethernet, to which lva-os will auto-connect to.

To see a guide on how to use lva-installer see [use_lva_installer](docs/use_lva_installer.md).
